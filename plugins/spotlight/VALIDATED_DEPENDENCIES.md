# Spotlight dependency authority

Indicator Labs is the managed journalist path. Open-source users apply the same
signed Engine plans directly. Engine's catalog and sealed plan own dependency,
model, skill, projection, update, rollback, and uninstall state.
`install-spotlight.sh` is a fail-closed pointer for old curl|bash pipes; it does
not install software or collect credentials.

Keep the catalog pins below aligned with Engine `catalog/catalog.json`. A
dependency change must update the Engine catalog/product plan and this file.
Neither path may request an unpinned `latest` dependency.

Reviewed pins currently consumed by both Engine installation paths:

- `@inkeep/open-knowledge` `0.54.3`
- `crawl4ai` `0.9.0`

Secrets enter Engine's operating-system credential broker: through Indicator
Labs' protected prompt for managed installs, or through the protected `bsig`
stdin/keychain flow for open-source installs. Values never belong in agent chat,
argv, shell history, or repository files. There is no localhost configure page.
