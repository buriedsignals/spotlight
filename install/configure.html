01 — Mode

Frontier or Local.

Pick one. Frontier uses a hosted model — faster investigations, higher quality, but queries go to the provider. Local runs a journalism model on your own machine — private by design, nothing leaves your laptop.

02 — Agent

Pick your AI agent.

Spotlight is a skill bundle — it runs inside an agent runtime. Subscription runtimes (Claude Code, Codex, Pi) authenticate via their own login: no API key needed. Only OpenCode requires a provider key (pay per token).

Checked live against the provider when you finish — a typo fails here, not mid-investigation.

02 — Agent

Harness + model.

One harness, pick the model that matches your hardware. Every local install runs the Flue-on-Pi harness over llama.cpp: the orchestrator delegates to an independent investigator and fact-checker (verification independence is structural), sessions are durable and resumable, scraped pages are auto-distilled by a resident RLM, and long conversations compact automatically. The installer preconfigures all of it — you never touch the serving layer.

Vault app.required

Spotlight archives verified findings into a Markdown vault — entities, methodology, tools — with wikilinks and YAML frontmatter. Pick the app you read it with.

One manual step after install:
  1. The installer launches Obsidian for you (installing it first if needed)
  2. In Obsidian → Settings → General → Advanced → toggle Command Line Interface ON
  3. Keep Obsidian running whenever you ingest findings into the vault
Tolaria must already be installed from a build you trust — Spotlight never downloads it. The vault is standard Markdown with YAML frontmatter, so it stays readable from Tolaria, Git, and your agent tools.
Two folders.required
